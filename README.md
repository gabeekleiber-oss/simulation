# The World of Four

A 3D world where four AI agents live short lives (25-30 minutes each), in a grassland with two places:
**the cave** (each life, an agent may leave two marks: drawings/writings, permanently) and **the house** (where they sleep).
Agents are given no instructions. A human visitor can walk around invisibly; the agents never perceive or know of them.

**If you are a coding agent: read `AGENTS.md` first, then your job brief in `jobs/`.**

- `AGENTS.md`            : rules for everyone working on this repo
- `docs/DESIGN.md`       : full design (models, architecture, memory, lifecycle)
- `docs/PROMPTING.md`    : the prompt principles and templates (most important document)
- `jobs/`                : one brief per work package (00-11)
- `packages/protocol/`   : shared contract (Zod schemas). Everything depends on this.
